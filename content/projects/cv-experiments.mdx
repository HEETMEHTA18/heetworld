# Computer Vision Experiments

Computer Vision has become one of my major areas of exploration. This is the running log of that work.

## What I'm exploring

- Image processing and OpenCV fundamentals.
- Object detection and image classification.
- Segmentation and tracking.
- Dataset preparation, model training, and evaluation.

## A practical system

One system I've been building processes a camera feed to **detect and count objects** in real time. It forces every stage of the workflow to actually work together:

**Image → Preprocessing → Detection → Classification → Counting → Visualization**

## Why this approach

Building the end-to-end loop — rather than only studying one layer — is how computer vision stops being a black box. Each experiment adds one more stage I can trust in production-style conditions.
