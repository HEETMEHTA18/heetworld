# Code Pie (formerly BinaryBattles)

A scalable, real-time competitive programming platform built with Node.js services, PostgreSQL, Redis, and a React/Vite frontend. Designed for classroom tournaments, hackathons, and everyday practice coding. Now maintained by the Tatvam team (Department of Computer Engineering, CSPIT, CHARUSAT University).

## Architecture & Scale

- Contributor in an 18-member team; owned the contest module and its architecture
- Managed submission-queue capacity and rate thresholds across Redis/Bull queues and isolated Docker workers
- Scaled to a distributed 3-node setup (Nginx load balancer, PgBouncer, Redis workers) sustaining 1,000+ requests per second
- Handled contest workflow stages (worker runner, Redis queue/cache, PostgreSQL) and contest-page APIs (problem statements, results, submission history)
- Documented 3-PC LAN topology: PC-MAIN (172.16.2.10) + PC-DB (172.16.2.9) + PC-CACHE (172.16.2.11)

## Features

- **Tournament Mode** - Bulk-create N parallel 1v1 rooms, global leaderboard, admin-controlled contests with countdown
- **Tic-Tac-Toe Grid** - Solve questions to claim cells; first to make a tic-tac-toe wins instantly with knife system
- **Monaco Editor** - Fully syntax-highlighted C/C++ editor with multi-language support (C, C++, Python, SQL)
- **Submission Insights** - Per-problem runtime/memory distribution, accepted-solution percentiles, private notes
- **Horizontal Scaling** - Nginx load balancer, Bull/Redis task queues, isolated worker node executors
- Built the contest workspace with in-progress code persistence in localStorage
